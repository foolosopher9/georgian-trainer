# Тренажёр грузинского языка

Тренажёр для подготовки к тесту по грузинскому языку для получения гражданства Грузии.
Источник вопросов — «ტესტები საქართველოს მოქალაქეობის მოპოვებისათვის ქართულ ენაში» (2024), 200 вопросов.

Работает в браузере без сервера, прогресс хранится в localStorage, устанавливается на телефон как PWA и работает офлайн.

## Возможности
- Каталог вопросов со статусами «новый / учу / выучен», поиском и фильтрами
- Тренировка по изучаемым вопросам с мгновенной проверкой и интервальным повторением выученных
- Экзамен (число вопросов, проходной балл, таймер и способ выборки настраиваются)
- Работа над ошибками, режим карточек, статистика по каждому вопросу, оценка готовности
- Шпаргалки по подразделам и перевод вопросов на русский (сгенерированы ИИ, могут содержать неточности)
- Экспорт и импорт прогресса в JSON

## Разработка
```bash
npm install
npm run dev          # локальный сервер
npm run validate     # проверка данных (вопросы, переводы, шпаргалки)
npm run build        # сборка в dist/
```

Данные: `src/data/questions.json` получен из `data/tests.pdf` скриптом `npm run parse` (нужен `pdftotext` из poppler).
Переводы собираются из `scripts/translations/*.json` командой `npm run translations`.

Деплой на GitHub Pages происходит автоматически при пуше в `main` (`.github/workflows/deploy.yml`).
